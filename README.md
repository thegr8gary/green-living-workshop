# green-living-workshop

「超高齡社會下的綠色生活」國際工作坊（2026/8/1–8/7）的成果介紹網站。

老師於 2026-08-18 交辦，起因是 K-Bus（音譯）希望把工作坊成果與過程放上網路，讓各參與國的老師能帶回自己的學校介紹與交流。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 網站本體。單一檔案，CSS/JS 內嵌，無建置流程、無 CDN 依賴 |
| `design-tokens.md` | 視覺規則的單一真實來源。改樣式前先讀這份 |
| `SPEC.md` | 網站內容與形式規格書。老師的口頭指示已逐項整理，含出處時間戳 |
| `assets/` | 網站素材。目前有 `map-bw.png`（地圖背景，複製自「分組報告連結啟動頁」），日後放過程照片 |

**第一版（預審用）已完成**：完整頁面骨架 + 7 組簡報連結（已驗證可開啟），缺素材處以「待補素材」區塊標示要跟誰拿什麼。素材到齊後只需填空，不需重做。

## 動工前的兩個前提

**這兩件事沒確認之前不建議開始做：**

1. **九月工讀費尚未確定** — 老師說會向 K-Bus 爭取（比照每月兩萬），但當時尚未有回覆
2. **學生作品公開授權未討論** — 7 組簡報是 Canva／Google 分享連結，放上公開網站等於對外發布學生作品。會議中完全沒談到這點
3. **Canva 連結會導向「編輯」網址** — 2026-08-19 實測，6 個 `canva.link/*` 短網址最終都轉到 `canva.com/design/.../edit?...`。公開發布前應改成檢視／簡報模式的分享連結，否則任何人點進去都可能改到原始檔案

其餘待確認事項（網域位置、語言版本、Final 成果形式、完成時限）見 `SPEC.md` 第五節。
